# Homebrew Tap

Homebrew packages maintained by Leo6Leo.

## WhisprStream

```bash
brew install --cask Leo6Leo/tap/whispr-stream
```

WhisprStream's public build is self-signed and not notarized. Its Cask removes
quarantine only from the installed app; it does not disable Gatekeeper.

## CLD

```bash
brew install Leo6Leo/tap/cld
```

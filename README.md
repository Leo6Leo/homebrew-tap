# Homebrew Tap

Homebrew packages maintained by Leo6Leo.

## WhisprStream

```bash
brew install --cask Leo6Leo/tap/whispr-stream
```

WhisprStream's public build is self-signed and not notarized. Its Cask removes
quarantine only from the installed app; it does not disable Gatekeeper.

The Homebrew publishing flow is adapted from
[@logonoff](https://github.com/logonoff)'s
[SuperOpt](https://github.com/logonoff/superopt) and
[homebrew-bucket](https://github.com/logonoff/homebrew-bucket). Thank you for
sharing the simple release setup.
